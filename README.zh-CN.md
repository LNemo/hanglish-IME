# Hanglish IME

**会说韩语，就用拉丁字母把它打出来。**

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md)

Hanglish 是一款实验阶段的输入法，面向**会说韩语，但难以用韩文书写的人**。用拉丁字母输入你熟悉的韩语词语，Hanglish 会提供对应的韩文候选。不必先学会韩语键盘布局，就能开始使用。

例如，你会说 *jeoneun haksaengimnida*（“我是学生”），就可以输入这句话的罗马字拼写，而不必逐个输入韩文字母。

| 输入 | 韩文候选 | 含义 |
|---|---|---|
| `jeoneun haksaengimnida` | 저는 학생입니다 | 我是学生。 |
| `imnida` | 입니다 | 表示“是”的正式礼貌形式。 |
| `testreul sihaenghanda` | test를 시행한다 | 进行测试；保留英文单词 `test`。 |

这些示例已纳入内置引擎的基本功能测试，但不代表所有句子都能正确转换。

## 使用方法

1. 在 macOS 输入菜单中选择 **Hanglish**。
2. 用拉丁字母输入韩语发音，保留词语之间的空格。
3. 按 **Enter** 或 **Tab** 请求韩文候选。
4. 用 **Tab / Shift+Tab** 或 **下 / 上方向键**切换候选，按 **Enter** 确认输入。
5. 如需保留原来的拉丁字母文本，按 **Esc**。

输入以韩国《国语罗马字表记法》（Revised Romanization）为基础。你习惯的非正式拼写不一定都能识别。这是一款韩语输入工具，不会把英文句子翻译成韩语，也不支持语音听写。

韩语发音并不总能唯一确定写法。Hanglish 会尝试还原你想表达的词语，但也可能给出错误候选。选择候选仍需要一定的韩文识读能力；如果完全不认识韩文，可能需要别人帮忙核对结果。目前还没有候选读音提示或翻译功能。

## 支持环境与发布状态

**当前原生原型：macOS 0.2.6（构建 8），Apple Silicon，最低部署目标为 macOS 14 或更高版本。** 目前仅在 macOS 27 上进行了本地验证，仍需在 macOS 14 上单独确认兼容性。Windows、Android 和 iOS 输入法尚未实现。

**目前尚未发布 GitHub Release。** 仓库当前为私有仓库。原创代码采用非商业用途条款，模型的公开分发方案仍在准备中。

如果你已收到开发版安装包，请参阅 [macOS 安装指南（English）](native/macos/README.md)或[한국어版](native/macos/README.ko.md)。完整安装包包含转换引擎、模型和 Python 运行时。安装后，转换在本机进行，不会把输入的文本发送到服务器。使用该安装包不需要开发服务器、Tailscale，也不需要另行安装 Python。

安装程序默认显示英文，并提供韩文界面。开发版安装包使用 ad-hoc 签名。Developer ID 签名和 Apple 公证尚未完成，各应用的兼容性也仍在测试。

## 当前限制

- 这是实验阶段的输入法，不是成熟的拼写或语法检查工具。
- 语音变化、歧义词、生僻词以及韩英混合输入都可能导致错误候选。
- 在开发过程中已经使用过的 1,000 句回归测试数据中，所选引擎的首选候选答对 954 句，前五个候选包含可接受答案的有 975 句。**这不是独立的真实使用准确率评估。** 首选候选仍有 46 句错误。
- 尚不支持在组合中的字符串内部移动光标编辑，也不支持按词重新转换。
- 实验性网页界面仅用于本地开发，不属于此仓库的分发范围。
