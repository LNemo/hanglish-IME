# Hanglish IME

**말할 수 있는 한국어를 로마자로 입력하세요.**

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md)

Hanglish는 **한국어를 말할 수 있지만 한글로 적는 데 어려움을 느끼는 사람**을 위한 실험 단계의 입력기입니다. 알고 있는 한국어 단어를 로마자로 입력하면 한글 표기 후보를 제안합니다. 시작하기 위해 한국어 키보드 배열을 먼저 배울 필요는 없습니다.

예를 들어 *jeoneun haksaengimnida*라고 말할 수 있다면, 한글 자모를 직접 입력하는 대신 그 발음을 로마자로 적을 수 있습니다.

| 입력 | 한글 후보 | 뜻 |
|---|---|---|
| `jeoneun haksaengimnida` | 저는 학생입니다 | 자신이 학생이라고 소개하는 문장 |
| `imnida` | 입니다 | ‘이다’의 격식 있는 높임 표현 |
| `testreul sihaenghanda` | test를 시행한다 | 영어 단어 `test`를 유지하면서 한국어로 입력 |

이 예시들은 내장 엔진의 간단한 실변환 테스트에 포함되어 있습니다. 모든 문장을 정확하게 바꿔 준다는 의미는 아닙니다.

## 사용 방법

1. macOS 입력기 메뉴에서 **Hanglish**를 선택합니다.
2. 한국어 발음을 로마자로 입력합니다. 단어 사이의 공백도 함께 입력합니다.
3. **Enter** 또는 **Tab**을 눌러 한글 후보를 요청합니다.
4. **Tab / Shift+Tab** 또는 **아래 / 위 방향키**로 후보를 바꾸고, **Enter**로 확정합니다.
5. 원래 로마자 입력을 유지하려면 **Esc**를 누릅니다.

입력은 한국어 로마자 표기법을 바탕으로 합니다. 익숙한 비공식 표기가 항상 지원되는 것은 아닙니다. 영어 문장을 번역하는 도구가 아니라 한국어 단어를 적는 도구이며, 음성을 듣고 받아쓰는 기능도 없습니다.

한국어는 발음만으로 원래 표기를 하나로 결정할 수 없습니다. Hanglish가 의도한 표기를 추정하지만 잘못된 단어를 제안할 수 있습니다. 후보를 고르려면 한글을 어느 정도 알아볼 수 있어야 하므로, 한글을 전혀 읽지 못한다면 결과 확인에 도움이 필요할 수 있습니다. 후보의 읽는 법이나 번역을 보여 주는 기능은 아직 없습니다.

## 사용 가능한 환경

**현재 네이티브 시제품: macOS 0.2.6(빌드 8), Apple Silicon, 최소 배포 대상 macOS 14 이상.** 지금까지 실제 로컬 검증은 macOS 27에서만 진행했으므로 macOS 14 호환성은 해당 운영체제에서 별도로 확인해야 합니다. Windows·Android·iOS 입력기는 아직 구현하지 않았습니다.

**GitHub Release는 아직 발행하지 않았습니다.** 저장소는 현재 비공개입니다. 자체 코드에는 비상업 이용 조건을 적용하며, 모델의 공개 배포 방식은 준비 중입니다.

설치와 입력 소스 설정은 [macOS 설치 안내(English)](native/macos/README.md) 또는 [한국어 안내](native/macos/README.ko.md)를 참고하세요. 완성된 설치 패키지는 변환 엔진·모델·Python 런타임을 포함합니다. 설치 후 변환은 컴퓨터 안에서 실행되며 입력한 텍스트를 서버로 보내지 않습니다. 개발 서버·Tailscale·별도 Python 설치도 필요하지 않습니다.

설치기는 영어를 기본으로 표시하고 한국어 번역을 지원합니다. 개발용 설치 파일은 ad-hoc 서명 상태입니다. 릴리스 모드 패키지는 Developer ID 서명과 Apple 공증을 거칩니다. 개별 패키지의 상태는 manifest와 공증 로그에서 확인할 수 있으며, 앱별 호환성은 계속 검증 중입니다.

## 현재 한계

- 실험 단계의 입력기이며 완성된 맞춤법·문법 검사기가 아닙니다.
- 발음 변화, 동음이의어, 생소한 단어, 한국어·영어 혼용에서 잘못된 후보가 나올 수 있습니다.
- 선택된 엔진은 개발에 이미 사용된 회귀 자료 1,000문장 중 첫 후보 954건, 상위 5개 후보 975건을 맞혔습니다. **독립적인 실제 사용 정확도를 측정한 수치가 아닙니다.** 첫 후보 오류 46건이 남았습니다.
- 조합 중인 문자열 내부의 커서 편집과 단어별 재변환은 아직 지원하지 않습니다.
- 실험용 웹 화면은 로컬 개발 도구이며 이 저장소의 배포 범위에서 제외합니다.

## 개발자를 위한 안내

변환기 소스, macOS 입력기, 빌드 도구, 테스트를 포함합니다. 모델 가중치, 내려받거나 생성한 데이터, 로컬 실험 산출물, 설치 이미지는 포함하지 않습니다.

**새로 clone한 소스에서 모델 없는 기본 변환을 실행할 수 있습니다. 완전한 학습 엔진과 설치 파일에는 추가 자산이 필요합니다.** [개발 환경 준비 안내(영어)](native/macos/README.md#build-and-verify)에 잠긴 의존성 설치, 자산 검사, 신뢰할 수 있는 로컬 설치본에서 가져오는 절차를 정리했습니다. [자산 잠금 파일](native/macos/Packaging/runtime-assets.lock.json)과 정확히 일치하는 번들만 가져올 수 있으며, 출처 메타데이터 정규화 이후에는 이전 0.2.5 설치본이 현재 잠금과 일치하지 않습니다. 공개 모델 다운로드는 아직 제공하지 않습니다.

Xcode Command Line Tools가 설치된 Mac에서 저장소 루트를 기준으로 모델 없는 네이티브 검사를 실행할 수 있습니다.

```sh
bash native/macos/test.sh
```

조합 상태, 엔진 프로세스의 통신 처리, Swift 타입을 검사합니다. 실제 입력기 선택·키 입력·모델 변환의 성공까지 증명하지는 않습니다. 수동 키보드 진단은 `scripts/manual/`로 옮겼고 `--run`이 있어야 실행됩니다. import만으로 키를 보내지 않습니다. [개발 환경 안내](native/macos/README.md#build-and-verify)의 기본 테스트 명령을 사용하세요. 연구용 테스트에는 추가 자산이 필요할 수 있습니다.
