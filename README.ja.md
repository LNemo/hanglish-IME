# Hanglish IME

**話せる韓国語を、アルファベットで入力。**

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md)

Hanglish は、**韓国語を話せても、ハングルで書くのが難しい人**のための実験段階の入力メソッドです。知っている韓国語の単語をラテン文字で入力すると、ハングルの表記候補を提案します。使い始めるために韓国語のキーボード配列を覚える必要はありません。

たとえば *jeoneun haksaengimnida*（「私は学生です」）と言えるなら、ハングルの文字を一つずつ入力する代わりに、その発音をアルファベットで入力できます。

| 入力 | 韓国語の候補 | 意味 |
|---|---|---|
| `jeoneun haksaengimnida` | 저는 학생입니다 | 私は学生です。 |
| `imnida` | 입니다 | 「〜です」にあたる、改まった丁寧な表現。 |
| `testreul sihaenghanda` | test를 시행한다 | テストを実施する。英単語 `test` はそのまま残す。 |

これらの例は、同梱エンジンの基本的な動作確認テストに含まれています。あらゆる文を正しく変換できるという保証ではありません。

## 使い方

1. macOS の入力メニューで **Hanglish** を選びます。
2. 韓国語の発音をラテン文字で入力します。単語間のスペースも入力します。
3. **Enter** または **Tab** を押して、韓国語の候補を表示します。
4. **Tab / Shift+Tab** または **下 / 上矢印キー**で候補を切り替え、**Enter** で確定します。
5. 元のラテン文字のまま確定したい場合は **Esc** を押します。

入力は韓国語の改訂ローマ字表記法（Revised Romanization）を基本としています。普段使っている非公式なつづりには対応できない場合があります。英語の文章を韓国語に翻訳するツールではなく、韓国語の単語を入力するツールです。音声入力にも対応していません。

韓国語は発音だけでは表記が一つに決まりません。意図した表記を推定しますが、誤った単語を提案することがあります。候補を選ぶにはハングルをある程度読める必要があり、まったく読めない場合は結果の確認に手助けが必要かもしれません。候補の読み方や翻訳を表示する機能は未実装です。

## 対応環境と配布状況

**現在のネイティブ試作版：macOS 0.2.5、Apple Silicon、macOS 14 以降。** Windows・Android・iOS 用の入力メソッドは未実装です。

**GitHub Release はまだ公開していません。** リポジトリは現在非公開で、プロジェクトのライセンスとモデルの公開配布方法を準備しています。

開発用インストーラーを受け取った方は、[macOS インストールガイド（English）](native/macos/README.md) または [한국어版](native/macos/README.ko.md)を参照してください。完全なインストーラーには変換エンジン、モデル、Python ランタイムが含まれます。インストール後の変換は端末内で行われ、入力したテキストをサーバーに送信しません。開発サーバー、Tailscale、別途の Python インストールは不要です。

開発用インストーラーは ad-hoc 署名です。Developer ID 署名と Apple の公証は未完了で、アプリごとの互換性も検証中です。

## 現在の制限

- 実験段階の入力メソッドであり、完成したスペル・文法チェッカーではありません。
- 音の変化、曖昧な語、未知の語彙、韓国語と英語の混在などで誤った候補が出ることがあります。
- 採用エンジンは、開発中に使用済みの回帰テスト 1,000 文中、第一候補で 954 文、上位 5 候補以内で 975 文の正解を得ました。**独立した実利用での精度測定ではありません。** 第一候補の誤りは 46 文残りました。
- 変換中の文字列内部の編集や、単語単位の再変換は未対応です。
- 実験用 Web 画面はローカル開発ツールであり、このリポジトリの配布対象から除外します。

## 開発者向け

変換処理、macOS 入力メソッド、ビルドツール、テスト、開発記録を含みます。モデルの重み、ダウンロード・生成したデータ、ローカル実験の成果物、インストーラーのイメージは含みません。

**clone しただけでは、学習済みエンジン全体の実行や単体インストーラーのビルドはできません。** 必須ファイルは[エンジンのファイル一覧](native/macos/Packaging/engine-files.json)に記載されています。一部はローカル実験用パスに依存しており、公開配布前に再現可能なダウンロード・検証手順が必要です。

Xcode Command Line Tools を導入した Mac では、リポジトリのルートからモデル不要のネイティブ検査を実行できます。

```sh
bash native/macos/test.sh
```

検査対象は文字列の組み立て状態、エンジンプロセスの通信処理、Swift の型です。実際の入力ソース選択、タイピング、モデル変換の成功を保証するものではありません。`tests/` には import 時に動作する手動キーボード診断があるため、**pytest の全件実行は行わないでください。** 一般向けのテストコマンドを用意する前に、これらを分離する必要があります。
